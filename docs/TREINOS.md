# Meus treinos · Holy Planner 4.1

Abra **Meus treinos → Registrar treino**. Dê um nome à sessão, escolha a data em que treinou e adicione exercícios, cardio ou ambos. O diário aceita hoje e datas passadas.

## Musculação

- Informe o nome do exercício, a carga em **kg** e as repetições de cada série.
- **+ Série** copia os valores da série anterior; ajuste-os se a carga ou as repetições mudaram.
- **+ Exercício** inclui outro movimento. O campo sugere nomes já registrados para facilitar comparações.
- Para exercícios com peso corporal sem carga adicional, use **0 kg** e acompanhe as repetições.
- Use as observações para indicar se registra a carga total ou por halter, além de técnica, amplitude e dificuldade percebida. Mantenha o mesmo critério nas próximas sessões.

## Cardio

Registre a modalidade e a duração em minutos. A distância em **km** é opcional: deixe vazia se não tiver medido. Anote inclinação, terreno ou intensidade quando forem relevantes. Use nomes diferentes para atividades que queira comparar separadamente, como corrida na rua e corrida na esteira.

## Histórico e repetição

O histórico mostra séries, cargas, repetições e cardio de cada sessão. **Editar registro** permite corrigir dados. **Repetir treino** abre uma cópia para hoje: confira o que realmente realizou e salve a nova sessão. A sessão anterior é preservada. O menu de ações permite excluir um treino após confirmação.

O filtro de período afeta o histórico, os indicadores e os gráficos. A busca na barra lateral encontra títulos, observações do treino, exercícios e modalidades no histórico. Os indicadores continuam mostrando o período inteiro.

## Minha evolução

Escolha **Musculação** ou **Cardio**, selecione o exercício/modalidade e a medida que quer comparar:

| Musculação | Como é calculado por sessão |
| --- | --- |
| Maior carga | Maior carga informada entre as séries do exercício |
| Volume | Soma de carga × repetições de todas as séries do exercício |
| Repetições | Soma das repetições do exercício |
| Séries | Quantidade de séries registradas para o exercício |

| Cardio | Como é calculado por sessão e modalidade |
| --- | --- |
| Duração | Soma dos minutos |
| Distância | Soma dos km, disponível quando todas as atividades da modalidade têm distância |
| Ritmo médio | Duração total / distância total, exibido como minutos:segundos por km |

O gráfico apresenta uma sessão por ponto, em ordem de data e de registro, com intervalos horizontais iguais. Treinos do mesmo dia continuam separados. A tabela abaixo contém todos os valores. O cartão de variação compara o primeiro e o último valor medido **dentro do período escolhido**; com apenas uma sessão não há comparação. Quando o valor inicial é zero, não se calcula percentual.

Nomes que diferem apenas por maiúsculas e espaços são agrupados. Variações de nome, acentos e equipamento permanecem separadas. Exercícios repetidos dentro de uma sessão têm suas séries somadas. Cardio sem distância não gera ritmo; distâncias parciais não são usadas para calcular ritmo da sessão inteira.

Mais carga, volume ou tempo não significa, isoladamente, melhor desempenho. Compare sessões com condições semelhantes e considere também suas observações. Um ritmo menor significa menos tempo por quilômetro.

## Computador, celular e dados

Os treinos ficam no mesmo banco local dos outros recursos e entram em **Salvar backup**. O aplicativo Windows funciona offline. No celular, use o acesso pela rede local descrito em [APP.md](APP.md), com o computador e o servidor ligados. Salvar no celular atualiza o mesmo histórico disponível no computador. Edições concorrentes de uma sessão são detectadas para evitar sobrescrever mudanças de outra tela.

As imagens de validação usam exclusivamente dados de demonstração. Nenhum treino de exemplo é incluído no seu banco pessoal ou no pacote distribuído.
