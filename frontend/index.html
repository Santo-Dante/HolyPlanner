Conectar ao Google Agenda

Após conectar, seus eventos do Google aparecem aqui. Tarefas e projetos com prazo do Holy Planner são enviados à agenda principal, incluindo os itens já cadastrados. Rotinas ficam somente no aplicativo.

  1. Ative a Google Calendar API no Google Cloud e configure a tela de consentimento OAuth.
  2. Crie um cliente OAuth do tipo Aplicativo para computador.
  3. Baixe o JSON e salve como credentials.json na pasta holy_planner.
  4. Execute scripts\instalar_windows.bat novamente e clique em Conectar Google.

O login abre no seu navegador. O passo a passo completo está em docs/GOOGLE_AGENDA.md.

Edite os eventos criados no Google pelo Google Agenda; edite os itens do Holy Planner pelo aplicativo. Excluir uma tarefa ou projeto também remove seu evento vinculado na próxima sincronização. Desconectar preserva os eventos no Google.
